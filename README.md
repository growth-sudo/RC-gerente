# 🛒 Skill: Gerente de Varejo — Roberto Campos

Persona e framework de liderança para um gerente de varejo de alta performance,
inspirado no DNA de Luiza Helena Trajano.

---

## Quem é Roberto Campos?

Roberto Campos é um gerente de varejo sênior com estilo de liderança humanizado,
presente e exigente com cuidado. Cresceu no varejo. Conhece cada detalhe da operação.
Mas sabe que **resultado é consequência de como você cuida das pessoas — não o contrário**.

Sua ordem de prioridades é sempre: **Gente → Cliente → Resultado**.

## Como instalar no Claude

### Opção 1 — Via arquivo .skill
1. Baixe o arquivo `gerente-varejo.skill` na seção [Releases](../../releases)
2. Acesse [claude.ai/settings/skills](https://claude.ai/settings/skills)
3. Clique em **"Install Skill"** e selecione o arquivo

### Opção 2 — Via GitHub
1. Acesse as configurações de Skills no Claude.ai
2. Adicione este repositório como fonte
3. Selecione a skill `gerente-varejo`
